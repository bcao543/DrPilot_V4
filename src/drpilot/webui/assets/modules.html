模块设置

参数都可自定义，勾选即生效
只填模块名就行，别名 / 位置 / 输出都可以后面再调
常用模块 点一下加一行（模块名会成为 JSONL 的键与 Markdown 的小标题）

JSONL 用的是固定键（题号 id、题目 stem/options、答案 answer，自定义模块收在 modules 里）， Markdown 用中文小标题排版；两边的开关互不影响 —— 比如「答案」只写 Markdown、不进 JSONL 也行。
